# 🛡 Оберіг — помічник водія Uber / Lyft (Чикаго, Іллінойс, Мілвокі)

Безкоштовна програма для Android. Коли в **Uber Driver** або **Lyft Driver** приходить замовлення, Оберіг за секунду:

- **блимає екраном** кольором зони (дотики проходять крізь сигнал, кнопку Accept видно й можна натиснути);
- **каже голосом**, куди їхати можна, а куди ні:

| Колір | Голос | Що означає |
|---|---|---|
| 🔴 Червоний | «Червона зона. Заборонено.» | Найнебезпечніші квартали міста (стрілянина, викрадення авто з водієм) |
| 🟠 Темно-помаранчевий | «Нічна небезпечна зона. Заборонено.» | Жовта зона вночі (від заходу до світанку) |
| 🟡 Жовтий | «Жовта зона. Не рекомендуємо.» | Підвищений ризик, або маршрут іде через червону зону |
| 🟢 Зелений | «Зелена зона. Дозволено.» | Спокійний район |

- **рахує вигідність**: скільки чистими за годину (ціна − бензин − знос) і чи це «вигідно / так собі / невигідно».
- 🚨 **поліція й аварії**: коли Waze (або Google Maps) показує попередження, Оберіг вмикає **мигалку** (червоно-синю для поліції, жовту для аварій) і каже голосом: «Увага! Попереду поліція за 2 кілометри». Ближче до місця (за 500 м, можна змінити) попередження повторюється: «Поліція за 400 метрів. Будь уважний».
- 🆘 **SOS** для кількох людей (рідні, друзі поруч): «SMS усім» одним натисканням, WhatsApp кожному окремо або дзвінок 911. У повідомленні — «Мені потрібна допомога» і точка на карті.
- 🗺 **Карта**: детальні квартали **Чикаго** і **Мілвокі** (оновлюються щодня) плюс кожне місто **Іллінойсу** й південно-східного **Вісконсину** (Kenosha, Racine, Waukesha…) за річними даними ФБР.
- 📸 **зразки екранів**: програма сама робить скріншоти екранів замовлень і попереджень Waze, а кнопка «Надіслати у WhatsApp» у Журналі відправляє їх розробнику для покращення.

Програма **нічого не натискає** в Uber чи Lyft, вона тільки читає екран замовлення і підказує.

## 📲 Як встановити (для водія)

1. Відкрий на телефоні посилання на **останню версію**: <https://github.com/nexgen-fullstack/oberih/releases/latest>
2. Натисни на файл **`Oberih-….apk`**, і він завантажиться.
3. Відкрий завантажений файл → **Встановити**.
   - Якщо телефон питає «Дозволити встановлення з цього джерела?», відповідай **Дозволити**.
   - Якщо Play Protect каже «Невідома програма», натисни **Все одно встановити**.
4. Відкрий **Оберіг**. Одразу запуститься майстер **«Налаштувати все автоматично»**: він сам по черзі відкриє кожен потрібний екран, а тобі лишиться тільки натиснути «Дозволити» або поставити повзунок. Якщо щось пропустив, на Головній є кнопка «⚙ Налаштувати все автоматично». Що він налаштовує:
   1. **Карта небезпечних зон** завантажиться сама (потрібен інтернет, ~3 МБ).
   2. **Спеціальні можливості**: кнопка → «Встановлені програми» → **Оберіг** → увімкнути → Дозволити.
      Якщо перемикач **сірий** («Обмежене налаштування»): кнопка «Відкрити сторінку програми» → **⋮** угорі справа → **«Дозволити обмежені налаштування»** → повернутися і ввімкнути ще раз.
   3. **Робота без перерв**: дозволити роботу у фоні.
   4. **Голос**: натиснути «Перевірити голос».
5. Натисни **«Повна перевірка: імітація замовлення»**. Екран має блимнути, і прозвучить підказка. Якщо так, усе готово 🎉

**Порада.** У Uber Driver: Меню → Account → App Settings → Navigation → **Waze**. У Lyft Driver: Settings → Navigation → **Waze**. Waze сам попереджає про поліцію, аварії й перекриття і веде в об'їзд.

### Оновлення
Оберіг сам перевіряє, чи вийшла нова версія, і показує кнопку «Завантажити оновлення». Нову версію встановлюй поверх старої, налаштування збережуться.

## ❓ Часті питання

**Звідки програма знає, де небезпечно?**
Чикаго й Мілвокі: з відкритих даних поліції цих міст, з точкою кожного злочину, за останні 6 місяців. Інші міста Іллінойсу й Вісконсину: з даних ФБР (насильницькі злочини на 100 000 жителів за рік; один колір на все місто). Для Чикаго — з офіційних даних поліції ([Chicago Data Portal](https://data.cityofchicago.org/Public-Safety/Crimes-2001-to-Present/ijzp-q8t2)) за останні 6 місяців. Дані оновлюються щодня і запізнюються приблизно на тиждень. Головну вагу мають вбивства, стрілянина, викрадення авто з водієм і збройні пограбування. Людні місця (центр, River North) рахуються з поправкою на натовп, тому вони не «червоні» лише через те, що там багато людей.

**Це гарантія безпеки?**
Ні. Це статистика, яка допомагає вирішити швидше. Завжди довіряй своїм очам і чуттю.

**Звідки Оберіг знає про поліцію?**
З екрана Waze: Оберіг читає попередження, які Waze показує водієві, і повторює їх мигалкою та українським голосом. Тому Waze має бути **відкритий на екрані телефону**, а у Waze мають бути ввімкнені попередження про поліцію (Settings → Alerts & reports → Police). Якщо Waze сам не бачить поліцію (ніхто не повідомив), Оберіг теж не побачить: інших легальних джерел про поліцію немає. З Android Auto (екран у машині) це не працює.

**Програма не зреагувала на замовлення чи поліцію / помилилась**
Журнал → «Зразки екранів» → **Надіслати у WhatsApp**, після цього **«Очистити папку»** (програма сама запитає). Програма зберігає до 20 останніх скріншотів (≈1,5 МБ, старі видаляються самі) екранів Uber/Lyft/Waze (Android 11+), і за ними її можна навчити краще. На скріншотах можуть бути адреси пасажирів, тому надсилай тільки своїм. Скріншоти можна вимкнути в Налаштуваннях.

**Куди йдуть мої дані?**
Журнал, скріншоти і налаштування зберігаються тільки на телефоні. В інтернет іде лише адреса замовлення, щоб знайти її на карті (геокодер Android/Google або OpenStreetMap), і точки маршруту (OSRM). Більше нікуди.

**Чи можуть заблокувати акаунт Uber/Lyft?**
Оберіг тільки читає екран і нічого не натискає, як і популярні Para, Maxymo, Gridwise. Ризик дуже малий, але правила Uber/Lyft не дозволяють сторонніх програм прямо, тому повністю нульовим він не є.

## 🛠 Для розробника

Android, Kotlin + Jetpack Compose, minSdk 26 (Android 8+), без платних API і без власного сервера.

| Частина | Файл |
|---|---|
| Читання екрана Uber/Lyft, сигнал, голос | `service/OberihAccessibilityService.kt`, `AlertOverlay.kt`, `Speaker.kt` |
| Розпізнавання картки замовлення | `offer/OfferParser.kt` (+ тести `OfferParserTest.kt`) |
| Рішення: колір + вигідність | `offer/OfferAnalyzer.kt` |
| Карта ризику, ваги злочинів | `data/RiskGrid.kt`, `data/CrimeRepository.kt` (+ `RiskGridTest.kt`) |
| Адреси й маршрути | `data/Geo.kt` (Android Geocoder → Nominatim → назва району; OSRM) |

```bash
./gradlew testDebugUnitTest assembleRelease
```

Перед новою версією варто оновити дані ФБР по містах (≈20 хв): `python tools/build_towns.py` → `app/src/main/assets/towns.tsv`.

Випуск нової версії: підняти `versionCode`/`versionName` в `app/build.gradle.kts`, зібрати, створити GitHub Release з тегом `vX.Y.Z` і прикріпити APK. Ключ підпису (`keystore/` + `keystore.properties`) зберігається **тільки локально**. Без нього оновлення не встановиться поверх старої версії, тому зроби резервну копію.
